- T3 整合性検査器（T1、T2、#2）。完了条件: 参照整合、unknown を除く end\_state と rollback の全単射、戻り先の前方性、max の存在と有界性、carry の生成と消費、指標の存在、unknown の存在の各性質に、それだけを破る負例が一つ以上あり、検査器がそれぞれを該当の性質の違反として報告する
- T4 ハーネス契約の文書化（#3、#4、#8、#9）。三操作、スナップショット形式、ステージ本体・指標・ユーザー入出力・LLM クライアント・（#3 次第で）運用者応答のインターフェース。完了条件: 文書があり、人間が承認
- T5 toy-minimal の workflow.yaml（T2、T3、追加 B）。3〜4 ステージで、ロールバック、carry、フェーズ境界越え、ユーザー待ちを含み、追加 B の全遷移種別を覆う。完了条件: 検査器を通り、遷移種別ごとの被覆が表で示される。MECE の事前レビューは検証役（第5.9節）を通してから人間に出す
- T6 F1 の締め: 第6節 F1 の完了条件を検証役が判定し、人間がスキーマと契約を承認
